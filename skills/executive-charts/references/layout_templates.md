# 高管分析报告与看板排版布局规范 (Executive Layout & Template Standards)

在生成任何基于本设计系统的长图分析报告、管理驾驶舱或决策大屏时，使用以下排版栅格结构。标题排版与页面、卡片宽度遵循 [设计规范](design_standards.md)。

---

## 1. 黄金三段式布局体系 (Executive 3-Tier Layout System)

```
+-------------------------------------------------------------------------+
| [Header] 报告主标题 (结论先行) + 时间窗口 + 统计口径元数据               |
+-------------------------------------------------------------------------+
| [Tier 1] 核心 KPI 指标卡行 (4 列并排 / 2x2 响应式: grid-cols-2 lg:grid-cols-4) |
|   - mc01 基础数值卡   - mc02 同环比波动卡   - mc03 迷你走势卡   - mc04 进度卡   |
+-------------------------------------------------------------------------+
| [Tier 2] 核心图表证据链区 (双列对齐排版: grid-cols-1 md:grid-cols-2 gap-6)   |
|   +-----------------------------------+-----------------------------------+
|   | 证据链图表 1 (如 t06 营收/增速复合) | 证据链图表 2 (如 c02 产品排序条形) |
|   +-----------------------------------+-----------------------------------+
|   | 证据链图表 3 (如 r01 BCG四象限)   | 证据链图表 4 (如 fn01 EBITDA瀑布) |
|   +-----------------------------------+-----------------------------------+
|   | 证据链图表 5 (如 f01 转化漏斗)    | 证据链图表 6 (如 fn03 敏感度龙卷风) |
+-------------------------------------------------------------------------+
| [Tier 3] 高管行动决议与数据展示表格 (单列全屏通栏: w-full / col-span-full)   |
|   - tb01 标准多维全要素数据表 (14 列) 或 tb02 交互式多维检索明细表 (13 列)    |
|   - 严格遵循：文本居左 (text-left)、数值等宽居右 (text-right)、组件居中 (text-center)|
+-------------------------------------------------------------------------+
| [Footer] 数据来源 + 统计口径说明 + 报告生成经办部门元数据                 |
+-------------------------------------------------------------------------+
```

---

## 2. 响应式与宽度约束

- **表格列宽自适应**：必须包裹在 `overflow-x-auto border border-slate-200 rounded-lg bg-white shadow-2xs` 中，支持窄屏水平滚动，宽屏自然展开。

---

## 3. 图表高度与内边距推荐

- **柱状/折线/复合图 (`c01`, `t06`, `fn01` 等)**：容器高度 `h-[280px]` ~ `h-[320px]`；
- **环形/饼图/仪表盘 (`k01`, `m04` 等)**：容器高度 `h-[260px]` ~ `h-[280px]`；
- **散点/四象限/桑基图 (`r01`, `f02` 等)**：容器高度 `h-[300px]` ~ `h-[340px]`；
- **卡片内部 Padding**：`p-5` ~ `p-6`。
