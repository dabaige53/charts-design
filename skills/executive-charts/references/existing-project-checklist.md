# 接入已有项目

在已有页面中修改看板时，先确认数据来源、业务含义和保留的交互，再选择渲染入口。

## 确定范围

- 找到页面入口、构建命令、路由、认证和数据加载位置。
- 确认交付形式：Runtime 看板、导出网页，或现有框架中的组件。
- 处理当前页面时，确认数据、单位、计算公式、受筛选影响的组件，以及原有的导出和批注操作。
- 沿用组件稳定 ID；业务内容的修改以用户要求为准。

## 迁移非 MCP 看板

以原页实际可观察的效果为还原基准：采用 Charts Design 原生组件、看板或报告渲染器，替换渲染方式，同时最大程度保留页面结构、阅读顺序、业务内容和操作。标准主题、导航或控件不得成为套模板、重排或删减的理由。交付前从用户实际访问的地址确认页面加载 MCP 保存的看板或报告，并由官方运行时渲染。用 MCP 数据驱动自写阅读器、套用旧站 CSS、给导出 HTML 添加导航，或使用业务站专用补丁，均不算原生迁移。

1. 沿原站导航从范围内的第一个页面开始，无需先盘点全站。**转换每页之前**，在相同数据范围下观察原页，逐项记录要保留的内容和操作；条件显示、下钻和关联报告随该页记录。记录原页位置、内容或操作、对应 MCP 位置、对照结果；未核对的项目不能记为通过。
2. 每页记录至少覆盖原有的：
   - 区块布局、页面及区块阅读顺序、导航与入口；
   - 指标卡主值、单位、同比与环比、比较基期及计算含义；
   - 图表类型和实际绘制的全部系列、坐标轴、单位、图例及提示；
   - 筛选条件、默认值及每个受影响组件的联动结果；
   - 表格和明细的全部字段、单位、排序、分页、下钻入口与结果、导出范围及内容；
   - 报告原有正文、章节顺序、图文关系和阅读操作，以及原有批注等其他操作。
3. 保存为可编辑的 MCP 看板或报告，保留稳定 ID、数据与指标定义。预设不匹配时，先查 `charts://contract`、`chart_declarations` 和已有等价组件，再按实际声明能力选择原生 ECharts 或 HTML 自由组件等入口。使用自由组件时，逐项验证原页所需的筛选绑定和跨组件联动。使用报告路径和原生报告渲染器保留分析正文。以原生页面加载已保存的 MCP 看板或报告作为转换完成的条件。
4. 完成每页后，在原页与 MCP 预览选择相同数据范围，逐项对照记录：检查布局与阅读顺序、主值及同环比和基期、图表全部系列和轴及图例，切换各筛选并核对每个消费者，操作排序、明细下钻和导出并核对字段，逐段核对报告正文及图文关系。遗漏或不一致先恢复并复验；不能仅凭声明、组件存在或页面可打开判定通过。
5. 沿原站导航和页内入口复查所有范围内页面。没有等价方案时，记录页面位置、缺失内容或操作、对读者的具体影响及已查方案，标记该页和迁移**未完成**；需要补齐通用 MCP 能力时另行处理。只有用户明确同意具体缩减后，才能按约定缩小验收范围；不得自行删减或用业务站补丁冒充完成。

以下为不含经营数据的合成反例，用上述逐项对照判定：

| 原页 | MCP 结果 | 判定 |
| --- | --- | --- |
| 指标卡同时显示同比、环比及各自基期 | 只显示主值 | 未完成：比较值与基期缺失 |
| 趋势图显示两个系列及对应图例、坐标轴 | 缩成一条线 | 未完成：系列和图例缺失 |
| 明细含字段 A、B、C，并可下钻、导出 | 明细或导出遗漏字段 C | 未完成：明细字段缺失 |
| 报告含章节分析正文和图表 | 保留章名，用表格替代正文 | 未完成：分析正文缺失 |

## 映射组件

| 内容 | 接入要求 |
| --- | --- |
| KPI | 主值、单位和比较值绑定已定义指标；定义和解读进入详情 |
| 图表 | 根据需求选择预设、自由 ECharts 或 HTML；声明实际支持的动作 |
| 筛选 | 单选、多选、日期等条件绑定明确字段和消费者 |
| 表格 | 列键、标题、单位、排序与分页使用同一数据范围 |
| 详情 | 业务定义、公式、来源和明细对应当前组件与筛选 |

声明与渲染入口见 [组件渲染](component-html-generation.md)；CLI 校验见 [工作区命令](dashboard-workspace.md)。

## 集成与检查

1. 明确页面布局、数据查询、筛选状态和组件生命周期的负责模块。
2. 接通一个完整业务区域，检查原始数值、过滤结果及单位，再处理其余区域。
3. 更新时保留图表实例，卸载时清理监听和资源，隔离不同看板的状态。
4. 应用 [设计规范](design_standards.md)，检查标题、工具栏、表格对齐以及窄容器溢出。
5. 按 [项目测试规则](../../../docs/operations/testing.md) 检查本次改变的行为；交付说明尚未接通的能力。

## 从外部历史报表迁入 MCP

源报表由其他项目、BI 系统、旧网页或工作簿维护时，主 Agent 先委派一个独立子代理做完整源端审查。给它源版本、可读入口、指定页面和数据期间、允许使用的角色与证据位置。让它从原件出发，避免照着迁移草稿倒推需求。主 Agent 可同时检查目标 MCP 合同和数据可用性。当前项目内的日常改稿沿用已有声明和编辑流程。

**子代理交付。** 在业务工作区保存一份可复用的逐页对照表。先从目录、路由、标签、报告章节、弹层和条件可见分支列出页清单，再逐页跟踪控件定义、数据查询、事件处理和实际输出。每项记下稳定编号、源位置（文件与函数、工作表单元格或可重放操作）、适用角色与期间。每页逐类对数，确实没有的类别记 0，因权限或原件缺失而无法检查的类别记“未核实”。若原件经构建或发布，沿发布指针、索引和分区文件追到实际加载的快照，登记版本、文件指纹、角色和期间，使目标端能重放同一输入。区分界面文案、源端实测和目标合同；遇到文案与实测不一致时，两者都记入证据。

| 审查对象 | 源端要记录的细节 | MCP 映射 |
| --- | --- | --- |
| 筛选器 | 标签与内部值、选项来源与授权范围、默认/全选/清空、单选多选、日期、级联顺序、搜索，以及切页后哪些状态保留 | 记录 filter ID、field、op、values、selectionMode 和明确的 componentIds。表内筛选用 scope=table，只指向该表。核实目标宿主的选项和清除语义 |
| 关联条件 | 区分查询关联（两端键、粒度、连接类型、去重、空值）和界面联动。逐事件列出触发源、键、条件、更新对象、保持原值的对象、再次点击或清除的结果 | 查询侧先保持行数和聚合粒度。页面筛选使用显式消费者。图形点击需单独对照 Runtime 的联动规则和实际目标集合 |
| 图表 | 记录图形、系列字段、分组/堆叠、排序、Top N 与其他项、气泡大小/色阶、轴和单位、阈值、缩放、悬浮与点击 | 查 chart_declarations(code)，将标记、编码、指标和数据集逐项绑定。分航司的堆叠排名可核对 c03 的 categoryField、seriesField 和 stacked，气泡可核对 r02 的 x/y、sizeBy 和 colorBy |
| 表格 | 行粒度、列键与顺序、单位、合计、组内重算、初始排序、分页、表内搜索、下载范围和空态 | 记录 table ID、datasetId、列与聚合声明。分别比对屏幕首行、总行数、合计及 CSV，记录导出是否包含完整匹配行 |
| 指标与正文 | 对象、来源字段和业务定义、时间口径、公式及分子分母、汇总顺序、基期、空值/零分母、单位和精度。追踪 KPI、图例、表格、图注中同名指标 | 登记 source、dataset、metric 的稳定 ID。比例先分别汇总再相除时用 ratio；按原规则核实基期和舍入。报告保留正文、图注、来源及表内筛选，按需选 filtered-report |

审查表可直接使用以下列。一个筛选器影响多个组件时记全消费者；同一次点击对不同组件的预期不同，可拆为多行并沿用事件编号。

| 页 / 源项编号 | 源位置及定义 | 账号、期间、初始状态与操作 | 源端预期（变化 / 保持） | MCP 页 / 声明 ID 与支持方式 | 目标实测及证据 | 差异或缺口 |
| --- | --- | --- | --- | --- | --- | --- |

子代理交接时按页列明筛选、关联、图、表和指标的数量、证据来源及未覆盖入口。主 Agent 用同一张表补齐目标映射和实测。支持方式写“原生”“已有适配”或“能力缺口”，引用当前服务的合同、声明或实际运行证据。只从源端收集到的未知项保留“未核实”，避免填入猜测的公式。

**主 Agent 转换。** 使用[声明构建脚本](mcp-authoring.md)初始化每页文件，优先用连接版本原生筛选器、图形绑定和报告组件。原生运行时的点击联动可触及同数据集的其他组件，跨数据集还需匹配 linkGroup 与字段。按源端事件逐一验证点击影响的组件；永久筛选器的 componentIds 只用于定位永久筛选范围。例如，若选中一个气泡只应改变排名，就同时断言排名的系列发生变化、顶部 KPI 数值保持原值、清除后排名恢复。自定义 ECharts 快照、隔离的 HTML 和本地 Runtime 补丁各有宿主边界，相关能力须在目标版本及交付形式中验证。发现原生能力不足时，说明具体操作、受影响的范围和已有适配；若须新增 Runtime 行为或改变业务语义，再由用户决定取舍。

**验收。** 用同一快照、账号范围、月份和选中状态，重放默认、单筛选、组合、点击、清除、空结果，以及源端存在的跨页操作。点选前后都要试重复点击、空白清除；在穿透状态下执行分页、排序、列显隐和导出，观察是否意外清除或保留选择。导出范围用实际文件的行数、列数核对。记录可复算结果（例如分子/分母、分类与系列、行数），覆盖每个控件和每条联动的正反向断言。对照表中每项须有实测记录或具体缺口。涉及受限数据时，在实际交付宿主分别核对可见选项和受保护的数据文件。工具校验、实际宿主交互、线上访问分别记录证据。自行修复可还原的差异；仅当缺少必要源材料或确需改变业务行为时，把剩余决策一次说明，继续完成独立部分。交付注明缺口影响的页、指标与操作。
