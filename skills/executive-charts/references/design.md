# 经营分析选图与内容组织

视觉规则见 [看板设计规范](design_standards.md)。按业务问题选图，组合数量与布局由内容决定。

## 按问题选择表达

| 问题 | 可用表达 |
| --- | --- |
| 各对象差距多大 | 柱状、条形、哑铃、偏离图 |
| 数值如何随时间变化 | 折线、面积、阶梯、柱线组合 |
| 总量由哪些部分组成 | 堆叠、环形、树图、桑基 |
| 数据分布是否集中 | 直方图、箱线、密度、热力 |
| 哪些因素相关 | 散点、气泡、相关矩阵、网络 |
| 目标推进如何 | 进度、子弹、仪表、阈值图 |
| 变化由什么造成 | 瀑布、敏感性、指数对比 |

可通过 `chart_recommend` 查询预设，也可直接选择自由 ECharts 或 HTML/JavaScript。具体声明见 [组件渲染](component-html-generation.md)。

## 组织阅读顺序

- 月度复盘：核心数值、趋势、变化归因、明细。
- 运营监控：指标与目标、异常分布、负责对象和处理动作。
- 转化分析：漏斗、分组差异、投入产出和跟进明细。
- 情景预测：实际数据、假设、情景区间和触发条件。

KPI 用于数值比较，禁止描述。结论放在独立文字区或报告正文，定义与计算方式放在详情。图表标题说明所看的指标或问题，副标题只补充必要范围。

## 数据表达

轴、图例、Tooltip 和表格沿用指标的单位、精度与名称。预测与实际、目标与完成值需可区分。缺失值保持缺失；比例按明确的分子、分母计算。

表格默认表头与内容居中，同列保持一致。金额与小数精度由业务定义决定。组件数量、形态与排布参考 [布局选型](layout_templates.md) 和 [指标卡选型](kpi-cards.md)。
