# UI 组件与 MCP 接入整改计划

原计划日期：2026-11-10。本文保留方案范围、阶段与待确认事项；当前组件能力维护在 [组件清单](../ui-component-inventory.md)，分轮次检查与构建记录维护在 [交付记录](../records/2026-11-10-polish-validation.md)。

## 目标与范围

统一共享 React 组件、设计系统、独立画板和 MCP 应用。使用成熟的基础交互组件，保持图表、指标、筛选与表格语义。

本方案不包含工作台重设计、恢复用户已删除看板、发布部署或修改 MCP 注册。保留用户已有内容与设计。

## 实施依据

- 产品目标与强约束由 [产品上下文](../PRODUCT.md)维护，视觉和迁移保真要求由 [设计规范](../DESIGN.md)维护。
- 模块与构建边界由 Runtime 说明维护；组件接口与接入状态由组件清单维护。
- 编辑、版本、按组件加载和数据引用由项目资产说明维护；批注目标与实现分别标明。
- 任务验证按 [测试与 CI](../testing.md)和当前授权选取，不沿用历史轮次的全量授权。
