# 看板交付术语

本术语表区分看板和报告的访问方式。数据路径、权限和有效期见[自托管服务器](../operations/self-hosted-server.md#网页预览与分享)。

「只读」约束看板或报告的内容编辑、版本保存与发布。能否新增批注由独立的批注权限决定；只读页面可以明确授权为「可批注」。批注继续使用同一位置锚点和面板，不另设“评论”体系。

## 访问链接

**在线只读链接**：
访问服务端最新已保存看板或报告的只读链接，阅读者可查看和筛选内容。新链接可显式授予批注权限，旧链接不会因升级获得写权限。
_避免_：预览链接、只读链接（未说明访问方式时）

**在线编辑链接**：
访问服务端看板或报告的编辑链接，持有者可使用网页支持的编辑和版本管理功能。
_避免_：编辑链接（未说明访问方式时）

**独立分享链接**：
访问独立发布的只读看板或报告副本的链接，其内容以明确选择的已保存版本和数据为准。作者选择「仅查看」或「可批注」，后者允许向该分享的服务端新增批注；两者均不能修改内容。作者电脑离线后仍可访问，草稿后续修改不改变该副本。
_避免_：预览链接、只读链接（未说明访问方式时）

**本机编辑页／本机预览页**：
从本机项目打开的浏览器页面。编辑页可编辑内容和批注；预览页内容只读，可提交位置批注。批注持久保存在本机项目，不随分享自动外发。

**分享反馈**：
对应一个分享 ID、发布版本及已有组件／段落锚点的读者批注。作者按需从分享服务读取，并在原分享版本定位。相同版本的不同分享各自保存批注，不合并到当前草稿；密钥访问的读者显示为访客或未经验证的自填署名。
