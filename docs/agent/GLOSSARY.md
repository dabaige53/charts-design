# 看板交付术语

本术语表区分看板和报告的访问方式。数据路径、权限和有效期见[自托管服务器](../operations/self-hosted-server.md#网页预览与分享)。

## 访问链接

**在线只读链接**：
访问服务端已保存看板或报告的只读链接，阅读者可查看和筛选内容。
_避免_：预览链接、只读链接（未说明访问方式时）

**在线编辑链接**：
访问服务端看板或报告的编辑链接，持有者可使用网页支持的编辑和版本管理功能。
_避免_：编辑链接（未说明访问方式时）

**独立分享链接**：
访问独立发布的只读看板或报告副本的链接，其内容以发布时的版本和数据为准。
_避免_：预览链接、只读链接（未说明访问方式时）
