# 图标、标题区与原版数据绑定


## 适用范围与交互约束

本文约定组件交互、标题排版、操作区与数据绑定规范。旧独立 HTML 生成脚本与原网页构建已下线，相关规范转为新 UI 设计体系的通用准则。

应用导出提供 CSV、单图图片、HTML 快照和静态站点；宿主能力不足时明确说明不可用状态。

Runtime 看板、图表、KPI 和表格的标题与描述在左上角，操作位于右上角。图标使用 Lucide SVG，不使用字符、Emoji 或 icon font 冒充图标；图标按钮保留 aria-label、悬停提示和键盘焦点。菜单、表单及数据保留正常文字。图标和按钮保留 `b4C6dEBLto` / Sera 组件结构；图表图标操作为 24px，常规控件为 32px。组件尺寸见 [产品 React 组件](../design-system/project/react-ui.md)。

Runtime 图表标题不显示 C01 等代码标签；图表注册代码仅用于组件选型与渲染。它不代替组件稳定 ID。

图表右上角直接保留图表／数据表、导出数据、复制图片、全屏、指标定义与语义，以及适用的月／季度切换。窄卡片允许操作区换行。原图形的几何、指标卡主体、微图、复杂标记、单位、Tooltip 和定义内容维护在共享 React 组件与独立 TypeScript 图表模块中。

表格使用带 Tooltip 和可访问名称的图标提供“自定义列配置”和“导出 CSV”，保留底部分页和每页条数选择；表内搜索只搜索当前表。阅读时的列配置、排序、页码、筛选和粒度只影响当前查看状态，不写回正式设计。编辑状态的表格呈现可保存至 tableState，未知列、重复列和非法状态会拒绝。

预览与编辑分开。布局拖动与卡片缩放仅在编辑模式启用；新增、复制、删除组件和导入数据通过 API/CLI 完成。编辑时显示兼容的图表类型切换，目前 c01/c02 可互换，其他图表显示当前类型及无兼容类型的原因。位置批注已接入选点、框选、正文、回复与解决状态；宿主附件及离线展示边界见 [批注说明](annotation-composer.md)。

“放大图表”只在页面内的弹窗展示当前组件，四周保留背景，不调用浏览器全屏。工具栏以 Lucide Maximize2 / Minimize2 切换“放大图表”和“还原图表”，Esc 可还原；放大前后的粒度、图表／数据表状态保留。页首“页面全屏”才作用于整个看板；浏览器全屏中的菜单、Tooltip、说明弹窗及表格设置浮层挂载到当前全屏元素内。

静态 HTML 快照只读。独立网页部署包可在浏览器内筛选，但仍不提供设计编辑或上游数据刷新。独立网页和只读预览保留布局、批注、版本与导出操作入口，按实际权限禁用并显示原因；可编辑预览通过带 `edit` 权限的独立链接提供。8 位分享密钥不授予草稿修改或版本发布权限。

## 旧组件的数据联动


```json
{
  "kind": "legacy",
  "family": "chart",
  "title": "区域收入",
  "config": {"code": "c01", "data": {"categories": ["华东"], "values": [100]}, "presentation": {"axisLabels": {"x": "收入", "y": "区域"}, "seriesLabels": ["收入"], "tooltipValueLabels": ["收入"], "units": ["万元"], "tableHeaders": ["区域", "收入"]}},
  "binding": {
    "datasetId": "sales",
    "categoryField": "region",
    "categoryTarget": "categories",
    "measures": {"values": "revenue"}
  }
}
```

sales 必须是已有 Dataset；revenue 必须是与它绑定的指标 ID。`put_component` 自动归一化 datasetId 和 measures；校验器要求所有系列绑定完整。绑定不能改变原 config 快照，渲染时才计算视图。各筛选器仍需要明确列出 componentIds。

当前支持的系列映射见 `dashboard_runtime/bindings.py`：按一维分类聚合的原图形、mc01–mc06 与 mc11–mc14、mc16 指标卡、明细表。mc03 与 mc12 还需 timeField；mc11 的 percent、mc13 的 actual/target、mc14 的 currentValue/priorValue 以数值目标绑定，用于环形、子弹条与双期条形的几何。时间序列设置 timeGrain 后，日期字段必须声明为 date，并使用 ISO 日期。季度比例使用 SUM(分子)/SUM(分母)，不平均月度百分比。展示单位换算必须显式声明 scale。

未启用动态编码的气泡图 `r02` 的绑定使用 `categoryTarget: "clusters"`，并将 `measures` 的 `x`、`y`、`size` 分别绑定到三个已有指标。`categoryField` 是字符串类型的业务对象标识，例如代理 ID；每个标识汇总为一个气泡，标识也作为图上文字。筛选后按各指标定义重新汇总；缺少任一指标或气泡大小为负的对象不显示。点击气泡可临时筛选同一数据集中参与联动的其他组件，再次点击或清除筛选可取消。绑定气泡图的提示和数据表仅展示这三个指标，不自动计算比值。原有未绑定的气泡图保持原样。动态编码分支的等大点、显式面积编码、描述字段、提示框与跨数据集下钻统一见 [动态编码](dynamic-encoding.md)，不套用本段的三指标快照限制。

复杂网络、层级、矩阵、统计分布及 mc07–mc10、mc15 的动态绑定仍需专门变换契约；当前拒绝不完整映射，而不是补造数据或把图形简化成柱状图。这些图形的原版静态配置仍完整可用。


## 检查与维护

绑定、聚合和分页检查按 [测试与 CI](../operations/testing.md) 选择直接受影响的用例；不从本文启动整套测试。维护时机：标题、操作入口、保存边界、兼容切换或普通数据绑定约定改变时更新。
