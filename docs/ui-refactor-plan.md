# UI 组件与 MCP 接入整改计划

更新日期：2026-11-10。

## 目标与范围

统一当前 charts-design 的真实组件库、设计系统、独立画板和本项目 MCP 应用。筛选器、表格及基础交互采用成熟组件与交互规范，不只修改自制控件的外观。

本轮不重设计工作台页面。不恢复用户删除的组合看板，保留用户已有编辑及无关改动。

| 技术 | 职责 |
| --- | --- |
| React + TypeScript | 组件、应用与类型 |
| Tailwind CSS v4 | 语义化变量、样式与响应式 |
| shadcn/ui 官方 registry | 基础交互组件与组合结构 |
| TanStack Table | 交互表格列模型及状态 |
| Apache ECharts | 图表，保留原版编码与业务语义 |
| GridStack.js | Dashboard 位置、尺寸、拖拽与排序 |
| Lucide | 产品图标 |

## 架构与构建边界

1. `docs/design-system`、`docs/design-canvas` 保存设计资产；归档源码和示例数据不进入真实业务运行。
2. `runtime-ui/src` 保存 React 组件及独立的数据、宿主适配入口。展示组件只接收 props 与事件，不访问数据库或直接调用 MCP。
3. 应用适配层管理查看状态、工具调用、结果解析、能力检测和错误反馈。
4. `dashboard_runtime` 继续管理数据、指标计算、查询、持久化、版本、项目隔离与检查点。
5. 画布与应用使用相同组件实现，入口分别构建。构建只写自己的 `dist`；资源打包与画布更新是明确的独立步骤。
6. npm、Python、容器发布资源必须与后端资源路径一致。不得把设计预览成功当作 MCP 宿主接入完成。

先检查 `components.json`、现有组件、包管理器及兼容版本。使用 `@shadcn` 官方 registry；安装和使用前查询对应官方文档。保留 Radix base 与别名。按用户 2026-11-10 的明确要求直接应用 `b4C6dEBLto` 预设，项目颜色与业务内容单独维护，组件边距、边框和尺寸沿用官方源码与内置 variants。此次不运行验证或测试。

| 日期范围 | 官方 Date Picker 模式，Popover 与 Calendar |
| 数值范围 | Field、Input、Button；有实际需要才增加 Slider |

优先采用完整官方结构、内置 variants 及语义变量，统一高度、间距、文字层级、边框、圆角和焦点。保留键盘操作、焦点管理、可访问名称、禁用与选择反馈。

筛选与表格沿用既有稳定 ID、状态及事件。后端负责的搜索、排序和分页不改成只处理当前页。列拖拽与 Dashboard 布局拖拽分别处理。只清理本轮被替代且无独立职责的旧实现。

### 组件范围与画板

- 筛选：全局多维筛选；单选、多选、搜索、全选、清空与数量；数值和日期范围；已生效条件；图表联动条件；移除和清空。
- 图表：40 种注册图表及对应数据表；16 种指标卡；标题与说明；月／季切换、图／表切换、CSV、图片、复制、全屏；指标定义、公式、单位、来源和计算语义。
- 表格：标准与交互表格；搜索、排序、列显隐、列顺序、拖拽、恢复默认；分页、每页条数、总数和导出。
- 通用：按钮、输入、选择、复选、表单、标签、徽章、提示、浮层、弹窗、抽屉及反馈；覆盖必要的加载、空、错误、禁用和焦点状态。

一个组件类型一个画板，相关状态及附属操作集中在该画板。40 种图表与 16 种指标卡各自独立。同类相邻、多行排列。保留用户编辑，不添加组合看板导航，不给每张画板默认增加 Play。图表标题和描述介绍图表本身。

指标卡减少重复副标题，将必要目标、均值和比较信息靠近主数值表达，保留业务含义。

### 图表保真

归档定义迁入独立维护的 TypeScript 模块。逐项保留类型、标记、几何、比例、坐标、基线、排序、单位、精度、图例、标签、Tooltip、预测、置信区间、阈值、目标线及已有筛选、联动、下钻和动态编码。

复杂图表保留各自逻辑，不支持的配置明确报错。前端不重算业务指标。统计图仍由独立后端生成。

### MCP、布局与导出

保留 projectRoot 隔离、dashboardId、稳定组件 ID、expectedRevision、dashboard_view、按组件加载、候选项搜索分页、分块校验、请求顺序、编辑批次、检查点、恢复及冲突处理。

先打通一个真实数据流程，再扩展全部组件。宿主不支持剪贴板或全屏时明确反馈，不提供假成功。

React 管理内容，GridStack 管理位置。查看锁定；编辑支持拖拽缩放；按断点保存；取消恢复原布局；保存使用 begin → patch → finish 和版本检查。查看筛选、分页、排序与粒度不隐式持久化。

保留 CSV、单图图片、HTML 与独立静态网页导出。取消 PDF 导出，删除其专用入口、实现、依赖及当前产品说明，保留设计参考 PDF。先完成 MCP 交互，再恢复导出。
