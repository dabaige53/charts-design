# 服务器、Neon 与 Pages 生产验收

2026-11-21，使用测试项目 `live-accept-20261121040257-dc00e3`、看板 `live-check` 和合成内容，验证 Charts Design 0.6.0。网页入口为 `https://charts-design.pages.dev`，远程 MCP 入口为 `https://charts-design.49-51-184-179.sslip.io/mcp`，使用 Bearer 令牌。

| 项目 | 实测结果 |
| --- | --- |
| MCP | 创建看板，初始修订号为 1；随后通过公网 MCP 读取同一看板。 |
| 在线编辑 | 在 Pages 编辑页面修改并保存标题。MCP 读取到新标题 `Live acceptance edited through Pages` 和修订号 2。 |
| 重启恢复 | 仅重启 `charts-design-api-1`。公网健康检查返回 200，重新连接后标题不变，修订号仍为 2。 |
| 密钥分享 | 发布保存后的版本。错误的 8 位数字密钥返回 401；正确密钥返回 303，浏览器随后显示分享的看板。 |
| 撤销与清理 | 撤销后，已验证密钥的浏览器会话返回 410。手动触发已安装的清理服务，退出码为 0；MCP 不再列出该分享，服务器上的对应副本目录和清理任务文件均已删除。 |

数据库为独立 Neon 项目的 `production` 分支、`charts_design` 数据库。已确认 7 项迁移完成；运行容器不持有数据库所有者凭据。后端只发布到回环端口 `18160`，使用独立数据卷。Pages 网页代理持有专用源站令牌；直接访问源站网页不带该令牌时返回 403。

每六小时的清理定时器已启用。本轮验证了手动触发同一清理服务的结果，不是等待自然到期。测试看板保留，分享已撤销。部署及验收没有重启 Paseo，没有修改 CloudBase 或 R2 已有备份。
