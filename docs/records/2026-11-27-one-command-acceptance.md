# 一键验收与百万行实测

2026-11-27，北京时间。基线为 `968f56d`。Node.js 26 和实际网页查询 Worker 用于测量。使用合成数据与测试分享链接。

## 流程验收

- 数据初始化生成 48 行航线数据、四个看板和一份报告。「可筛选明细」按直营筛选后得到 24 行。
- 功能验收通过本机 stdio MCP 发现工具，通过 HTTP 验证预览与草稿隔离、保存及正式发布。对同一位置批注重试后只保留一条记录。
- 部署入口完成目标计划检查，Docker Compose 配置经远程 Docker 校验。线上验收使用已经部署的作者 MCP 和 Cloudflare Pages + D1。
- 百万行测试从本地 SQLite 初始化，在本机预览和正式 Cloudflare 分享页得到同一候选列表和 20,834 条筛选明细。每页返回的行数独立校验。Cloudflare 保存一条读者测试批注，并验证跨会话读取、作者反馈和只读权限。复跑返回同一个分享 ID。

## 百万行结果

| 指标 | 本机作者预览 | 本机分享 Worker | Cloudflare 分享 |
| --- | ---: | ---: | ---: |
| 第一次查询月份候选值 | 63–65 ms | 约 0.2 ms | 约 0.2 ms |
| Worker 启动并读取月份候选值 | — | 约 15 ms | 约 15 ms |
| 返回首批明细 | 约 2–3 ms | 0.72–0.75 s | 11.9–12.2 s |
| 已加载数据后应用筛选 | 130–185 ms | 20–21 ms | 30–31 ms |

线上发布包约 1.78 MB，首次发布响应约 23 秒。首次查看明细读取 123 个 Parquet 分片，两个筛选候选项读取 0 个分片。Worker 以五次查询的中位数记录候选项耗时。明细、数据筛选和发布每轮各测一次。数据链路结果来自 HTTP 和 Worker。

## 方案判断

48 行验收覆盖版本和批注等正确性要求，百万行验收检查数据量对请求的影响。建议在变更导出、分片、筛选或 Worker 后分别运行两个规模。

本机 SQLite 可以直接返回首批十行。当前分享 Worker 在返回首批明细前读取所需数据集的全部分片。此次测试的线上明细等待约 12 秒，耗时集中在首次加载。后续比较不同分片大小时，应一起记录请求数、读取字节数、解码耗时和结果行数。这个样本压缩后约 1.78 MB，分享服务以压缩包的 16 MiB 上限为准，行数由真实数据的字段宽度和压缩效果决定。
