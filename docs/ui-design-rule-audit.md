# 产品组件设计规则盘点

当前规则：KPI 禁止描述；图表支持预设和自由渲染。

## 强规则、弱规则和自由范围

| 层级 | 当前规则 | 执行位置 |
| --- | --- | --- |
| 强规则 | KPI 不添加描述、副标题、解读段落 | Runtime `put_component`、CLI 工作区内容校验；前端隐藏历史描述 |
| 强规则 | 每个图表要声明可用渲染入口，不能保存一个没有实现的预设代码 | Runtime 和 CLI 共用 `validate_chart_renderer`；前端支持三种入口 |
| 强规则 | 不编造数值、目标、基期和指标定义；单位与计算含义明确 | 数据与指标校验加生成约定；代码不能判断所有业务文字的真实性 |
| 强规则 | 操作入口与已实现能力一致 | 自由组件校验支持的绑定；数据表、图片操作按能力显示 |
| 强规则 | 稳定 ID、版本检查、项目隔离与数据引用保留 | Runtime 存储与修改流程 |
| 产品约定 | 共享标题和操作外壳；表格表头与内容默认居中；短表按实际行数展示 | 共享 React 组件 |
| 弱规则 | KPI 形态数量、mc16 使用数量、布局模板、图表推荐结果 | 选择建议，不限制生成 |
| 自由范围 | 图表类型、系列组合、坐标系、原生样式、SVG／Canvas／HTML、脚本交互、浏览器可执行 React | 原生 ECharts 和独立 HTML 自由组件 |

旧 executive-charts 的“只选注册图表”“必须使用布局模板”“mc16 配一句解读”等要求已被替换。历史配色、固定尺寸、航空业务叙事和图形选型建议，不自动成为产品强规则。

## 图表生成入口

三种入口共用 `kind: legacy`、`family: chart` 的存储结构。

| 入口 | 必要配置 | 能力和边界 |
| --- | --- | --- |
| 内置预设 | `renderer: preset`（可省略）、注册 `code`、`data`、`presentation` | 40 种默认图形、各自的数据表、已实现的数据绑定 |
| 自由 ECharts | `renderer: echarts`、任意非空 `code`、完整 `echarts` | 可直接使用已安装 ECharts 支持的系列、坐标和组合；不套预设几何与自适应样式；JSON 函数字符串不执行 |
| 自由组件 | `renderer: html`、任意非空 `code`、`html` | HTML、CSS、JavaScript、SVG、Canvas；可加载 HTTPS 资源及浏览器可执行 React；不内置 JSX 编译器 |

自由 HTML 在仅开启脚本的隔离 iframe 中运行，数据通过 `window.chartData` 提供。脚本不会获得主应用 DOM 或 MCP 工具权限。资源、网络与宿主限制见 [自由组件说明](echarts-options.md)。可以在组件内实现选择、切换与动画。

两种自由入口可显式提供 `table: {headers, rows}`，获得共享数据表和 CSV。未提供时隐藏图／表切换与 CSV。自由 ECharts 保留图片导出和复制；HTML 不显示依赖宿主 ECharts 实例的操作。

自由入口当前使用显式数据快照，不自动把代码转换成后端聚合或筛选变换。提交 `binding`、`datasetId`、`measures` 等未接通组合时明确报错。后端全局筛选、跨图联动和粒度重算仍沿用已实现的绑定入口；自由脚本的本地交互与这些能力不同。

**未注册预设代码现在会在保存前被拒绝，并提示改用自由入口。** 新代码不需要注册到40图表列表，但必须声明能实际渲染它的方式。不再依赖“后端存下来、前端报错”的缺口。

原生覆盖 `config.echarts` 仍可扩展内置预设。覆盖业务数据时不会自动同步后端指标或数据表，作者需要明确维护一致的数据含义。需要执行自定义回调、加载库或 React 时使用 HTML 入口，而不是把函数字符串伪装成 JSON 配置。

## KPI 内容规则

全部 mc01–mc16 均不允许添加描述。禁止字段：`subtitle`、`description`、`desc`、`note`、`detail`、`rankSub`、`trendLabel`、`gaugeSub`。新建和修改 KPI 会检查组件顶层及 config／presentation；CLI 工作区也检查。旧文档仍可读取，历史描述不再显示在卡片中。

允许：标题、主值与单位、同比环比、目标及基期数值、必要的数值标签、趋势和进度图形。辅助标签必须配合数值表达，不能借数值字段塞入分析段落。业务定义、公式、来源和计算边界放详情；分析结论放独立文本组件。

| 类型 | 允许的主体内容 |
| --- | --- |
| mc01 | 主数值、同比、必要辅助数值 |
| mc02 | 主数值、同比与环比 |
| mc03 | 主数值、微型面积趋势 |
| mc04 | 主数值、进度条、目标数值 |
| mc05 | 主数值、半环、基准数值 |
| mc06 | 两个同级指标名称和值、各自比较值 |
| mc07 | 排名值和简短排名标记；不显示排名描述段落 |
| mc08 | 主值、简短阈值标记和图标；不添加原因分析 |
| mc09 | 主值、两段比例及对应数值标签 |
| mc10 | 中位数与区间图、均值及样本数量 |
| mc11 | 主值、环形进度、目标数值 |
| mc12 | 主值、迷你柱趋势、同比 |
| mc13 | 主值、实际值、目标与最多三个区间 |
| mc14 | 本期与基期条形、数值和比较标签 |
| mc15 | 1–4 个名称／数值／变化条目，可带总值 |
| mc16 | 突出的主值、比较值；不再显示 note 解读 |

比较使用真实基准，非零比较字符串保留正负号。动态绑定按指标单位格式化，快照声明提供完整显示值。业务完成率可超过 100%，图形进度显示范围为 0–100。

KPI 专用形态数据校验仍有历史路径差异。本轮统一的是禁止描述的写入入口与展示规则，没有声称所有历史形态已共用同一个完整校验器。

## 内置图表的动态能力

普通系列绑定覆盖15个代码：`c01 c02 c03 c04 c06 c07 c08 d01 t01 t02 t04 t06 fn02 fn03 r02`。

动态 encoding 覆盖 `c03 r02 r03 k01 f02`，与前者重叠。其余预设可以合法快照显示，不自动获得筛选与聚合。mc07–mc10、mc15 在注册 KPI 绑定入口仍为快照。

- 绑定字段、指标和数据集必须匹配；比例按分子合计除以分母合计。
- 时间聚合需要日期合同；跨数据集联动需要明确业务字段关系。
- c01/c02 保留已实现的预设互换；自由组件通过完整声明修改，不复用该切换操作。
- 双轴不是全产品禁用项；已有 t06 与自由 ECharts 均可表达。
- 另有直方图、箱线图、回归三类 Seaborn 静态组件，独立于40个交互预设。

## 现有开放边界与未完成能力

1. 自由组件支持本地脚本交互，统一后端数据绑定和跨组件事件桥尚待接通。
2. 任意原始 JSX 的编译、外部扩展自动安装、地图资源自动注册不在本轮实现内；可在 HTML 中提供浏览器可执行代码和所需资源。
3. 自由图形与显式数据表的业务一致性仍由作者维护，保存校验只检查结构，不解释脚本含义。
4. 自由脚本运行失败时，组件显示错误并提供重试。
5. 旧参考文件仍保留历史信息。当前 skill 明确规定其不能覆盖新产品规则；后续修改这些文件时应按现行要求更新。
